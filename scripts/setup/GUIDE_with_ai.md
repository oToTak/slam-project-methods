# Покроковий алгоритм: налаштувати ПК для SLAM-прогонів (виконується разом із ChatGPT/іншою нейронкою)

Як користуватись: відкрий нейронку, встав їй **блок «Промпт для нейронки»** нижче, потім по одному давай кроки з розділів 1–5
(копіюй текст кроку цілком). Нейронка пояснює, що робити, ти виконуєш і вставляєш їй вивід команд.
Усі довгі команди — з цього файлу, їх не вигадувати.

## Промпт для нейронки (вставити першим повідомленням)

```

з NVIDIA GPU. Правила:
1. Говори українською, простими словами, без зайвої теорії.
2. Веди мене СТРОГО по кроках, які я тобі даю. По одному кроку за раз. Не вигадуй команд, яких нема в кроці;
   якщо мені треба щось інше — спершу запитай.
3. Для кожної команди скажи: де її запускати (PowerShell від адміністратора / PowerShell / термінал Ubuntu),
   що має з'явитись у кінці, і що надіслати тобі, якщо вийшла помилка.
4. Коли я вставляю вивід або помилку — розбери її і запропонуй мінімальне виправлення; не пропонуй видаляти файли,
   форматувати диски чи змінювати системні налаштування Windows без пояснення і мого підтвердження.
5. Ніколи не проси мене вставляти в чат паролі, токени (Hugging Face, GitHub) чи ключі. Токен я вводжу сам у термінал.
```

## 0. Що ми робимо і навіщо (30 секунд)

- **Головний ПК** (`TEODOR`, GTX 1660 SUPER) — **уже налаштований**. Нічого ставити не треба: у розділі 1 лише перевірка.
- **ПК брата** (RTX 3060 12 GB) — ставимо з нуля. Для цього потрібен **один архів** `slam-local-….tar.gz` (≈30 KB) зі скриптами.
  Він лежить на головному ПК у папці `T:\slam-data\bundle\` (беремо файл з найновішою датою; розділ 2 пояснює, як його передати).
- Далі на ПК брата: Windows-частина (WSL, драйвер) → одна команда встановлення → вхід у Hugging Face → тест → повернення результатів.
- Усі дані (великі `.mcap`, 6–20 GB кожен) качаються з Hugging Face на кожному ПК окремо. Передавати їх між ПК не треба.

Що знадобиться: доступ до обох ПК; акаунт Hugging Face з прийнятими умовами датасету `ucu-autonomous-ugv/ucu-slam-dataset-v1`;
Google Диск (або месенджер/флешка) для передачі архіву; на ПК брата ≥ 60 GB вільного місця на диску, де буде WSL, і оновлений драйвер NVIDIA.

## 1. Головний ПК: перевірка (≈2 хв)

**Крок 1.1** — у PowerShell (звичайний):
```powershell
wsl -d Ubuntu-22.04
```
**Крок 1.2** — вже в Ubuntu:
```bash
cd /mnt/t/my_repos/slam-project-methods
bash scripts/setup/10_verify.sh
```
Очікую в кінці: `ALL OK`. Якщо є `[FAIL]` — надішли нейронці весь вивід.

**Крок 1.3 (рекомендовано, один раз) — дати WSL більше пам'яті.** Зараз WSL бачить лише 7.7 GB з 15.8 GB.
У Блокноті створи файл `C:\Users\tteod\.wslconfig` з таким вмістом (рядки точно такі):
```
[wsl2]
memory=11GB
processors=10
swap=16GB
swapFile=T:\\wsl\\swap.vhdx
```
Потім у PowerShell: `wsl --shutdown` (це зупиняє WSL; не роби цього, поки йде прогін). Знову відкрий Ubuntu — готово.

## 2. Передати архів на ПК брата (≈5 хв)

**Крок 2.1** — на головному ПК відкрий у Провіднику Windows папку `T:\slam-data\bundle\` і візьми файл `slam-local-<хеш>.tar.gz` з **найновішою датою**.
(Якщо змінював скрипти — спершу закоміть і в Ubuntu: `cd /mnt/t/my_repos/slam-project-methods && bash scripts/setup/make_bundle.sh`; з'явиться новий файл.)

**Крок 2.2** — завантаж його на Google Диск (або відправ братові в месенджері як файл).

**Крок 2.3** — на ПК брата скачай файл у `Завантаження`/`Downloads`. Диск може перейменувати файл або запакувати в `.zip`
— тоді спершу розпакуй zip у Windows (ПКМ → «Видобути все»). Має вийти файл `slam-local-….tar.gz`.

---

## 3. ПК брата: Windows-частина (≈20 хв + перезавантаження)

Виконується на ПК брата. Крок 3.0 — перевірки, без змін.

**Крок 3.0 — перевірити перед стартом** (PowerShell):
```powershell
winver
Get-PSDrive -PSProvider FileSystem | Select Name,@{n='FreeGB';e={[int]($_.Free/1GB)}}
nvidia-smi
```
Потрібно: Windows 10 22H2 / Windows 11; на диску для WSL ≥ 60 GB вільного; `nvidia-smi` показує RTX 3060.
Якщо `nvidia-smi` не працює — оновити драйвер NVIDIA з nvidia.com (рекомендований Game Ready/Studio) і перезавантажити.
Якщо в BIOS вимкнена віртуалізація (SVM/VT-x) — ввімкнути (нейронка підкаже для його материнки).

**Крок 3.1** — PowerShell **від імені адміністратора**:
```powershell
wsl --install -d Ubuntu-22.04
wsl --update
wsl --set-default-version 2
```
Перезавантажити ПК. Відкрити «Ubuntu 22.04» із меню Пуск, створити Linux-ім'я та пароль (запам'ятай пароль — він потрібен для `sudo`).

**Крок 3.2 (лише якщо на C: менше ~80 GB вільного)** — перенести WSL на інший диск, напр. `D:`. Попроси нейронку пояснити кожну команду
й не виконуй, поки не зрозумів. Скелет (PowerShell):
```powershell
wsl --shutdown
mkdir D:\wsl
wsl --export Ubuntu-22.04 D:\wsl\ubuntu-tmp.tar
wsl --unregister Ubuntu-22.04
wsl --import Ubuntu-22.04 D:\wsl\Ubuntu-22.04 D:\wsl\ubuntu-tmp.tar --version 2
```
Після `--import` вхід стає під `root`: у Ubuntu виконай `echo -e "[user]\ndefault=<твоє_linux_ім'я>" >> /etc/wsl.conf`, вийди й `wsl --shutdown`.
`--unregister` видаляє лише щойно встановлений порожній Ubuntu — на цьому свіжому ПК у ньому нічого цінного ще нема.

**Крок 3.3 — `.wslconfig`** (щоб збірка CUDA не падала через брак пам'яті). У Блокноті створи `C:\Users\<ім'я Windows>\.wslconfig`.
Постав `memory` ≈ 70 % ОЗП (мінімум 8GB), `processors` = кількість логічних ядер мінус 2, `swapFile` — шлях на диску з ≥ 16 GB. Приклад для 16 GB ОЗП/12 ядер:
```
[wsl2]
memory=11GB
processors=10
swap=16GB
swapFile=C:\\wsl-swap.vhdx
```
Далі PowerShell: `wsl --shutdown`. Відкрий Ubuntu знову.

**Крок 3.4 — перевірка GPU в Ubuntu**:
```bash
nvidia-smi
```
Має показати RTX 3060. Якщо ні — крок 3.0 (драйвер), потім `wsl --shutdown`.

## 4. ПК брата: встановлення (≈30–60 хв, більшість часу — завантаження й збірка)

Усе — в терміналі Ubuntu.

**Крок 4.1 — розпакувати архів.** Підстав свої `<ім'я Windows>` та хеш (шлях з пробілами — в лапки):
```bash
ls /mnt/c/Users/*/Downloads/slam-local-*.tar.gz
tar -xzf "/mnt/c/Users/<ім'я Windows>/Downloads/slam-local-<хеш>.tar.gz" -C ~
cd ~/slam-local
ls scripts/setup
```
Має бути список файлів (`setup_all.sh`, `10_verify.sh`, …).

**Крок 4.2 — одна команда встановлення.** Попросить sudo-пароль (той, що ти створив у кроці 3.1); повторний запуск безпечний:
```bash
cd ~/slam-local
bash scripts/setup/setup_all.sh
```
Не закривай вікно. Якщо обірвалось — просто запусти ту саму команду ще раз. Лог: `~/slam-data/logs/setup_all_*.log`.
Успіх = в кінці `ALL OK`. Якщо `[FAIL]` або помилка — надішли нейронці **останні ~40 рядків** виводу. Типові випадки:
`Killed`/137 — мало пам'яті (крок 3.3); `operation timed out` — повтори команду.

## 5. ПК брата: вхід у Hugging Face і приймальний тест

**Крок 5.1 — токен (створює людина, чий це акаунт Hugging Face; нейронці не показувати).** На huggingface.co в акаунті, де прийняті умови
датасету `ucu-autonomous-ugv/ucu-slam-dataset-v1`: Settings → Access Tokens → створити **fine-grained read-only** токен.
Найпростіше й безпечніше: брат створює **власний** акаунт HF, приймає умови датасету й робить токен у себе — тоді нічого не пересилається.
Якщо токен твій — вводь його сам, сидячи за ПК брата, а не пересилай у месенджері. Токен вводять руками в термінал на кроці 5.2.
Після завершення робіт токен видалити/відкликати на сайті.

**Крок 5.2 — логін** (у терміналі Ubuntu; на питання «add token as git credential?» відповісти `n`):
```bash
~/.local/bin/hf auth login
~/.local/bin/hf auth whoami
```
`whoami` має показати акаунт.

**Крок 5.3 — приймальний тест** (качає seq01, 6.5 GB; потім DPVO; на RTX 3060 очікується швидше за 88 хв на 1660 SUPER):
```bash
cd ~/slam-local
bash scripts/accept_seq01.sh
```
В кінці буде `ACCEPTED` або `NOT ACCEPTED`. **Це не обов'язково помилка:** DPVO недетермінований, на головному ПК три однакові прогони дали
ATE 1.372 / 2.272 / 1.738 м (очікування 2.34 ± 0.30). Головне — `coverage 1.0`, `tracking_lost false`, ATE у межах 1–3 м. Якщо вийшло
NOT ACCEPTED, запусти ще раз `bash scripts/dpvo/run.sh ucu seq01` (2 рази) і порівняй числа в `~/slam-local/results/summary.csv`.
Помилка/зупинка до кінця прогону — надішли нейронці вивід.

**Крок 5.4 — повернути результати** (кілька MB):
```bash
cp -r ~/slam-local/results "/mnt/c/Users/<ім'я Windows>/Desktop/results_brother"
```
Папку `results_brother` на Робочому столі — на Google Диск Теодору. Також скинь `~/slam-data/logs/fetch_timings.csv` (час завантаження).

**Крок 5.5 — прибрати доступ** (коли закінчили на чужому ПК):
```bash
~/.local/bin/hf auth logout
```
