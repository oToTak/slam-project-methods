# Kimera-VIO (T6): mono+IMU or stereo only?

Research only, no code and nothing was built (checked 2026-11-16 against `master` @ ce8c59b, 2025-02-10). Kimera-VIO is designed for stereo + IMU; the README describes it as a pipeline "from **Stereo** + **IMU** data" that "can optionally use **Mono** + **IMU** data instead" (https://github.com/MIT-SPARK/Kimera-VIO/blob/master/README.md), so mono+IMU exists on paper: the folder `params/EurocMono` is on master (https://github.com/MIT-SPARK/Kimera-VIO/tree/master/params/EurocMono) and the README says to point `PARAMS_PATH` of `scripts/stereoVIOEuroc.bash` at it, but it is documented only for EuRoC (it just ignores the right image) and the executables are still called `stereoVIO*`. In practice that path is not working: issue #254 "EurocMono params on master gives poor VIO performance" (https://github.com/MIT-SPARK/Kimera-VIO/issues/254, open, 5 comments, no fix) reports poor accuracy even on EuRoC; issue #247 "Mono-inertial Support" (https://github.com/MIT-SPARK/Kimera-VIO/issues/247, open, 0 comments) reports a fatal StereoFrame "baseline after rectification differs from nominal" error when running mono; issue #231 (https://github.com/MIT-SPARK/Kimera-VIO/issues/231, open, 0 comments) is another unanswered custom-data failure. The README says "Tested on Ubuntu 20.04" only, and the build needs GTSAM >= 4.1, OpenGV, DBoW2, Kimera-RPGO and a bundled ANMS, all from source (the project's own docker image is the supported shortcut), which is a heavy stack to pin on Ubuntu 22.04 without sudo-free apt packages, and the last commit on master is from February 2025. Our UCU data is mono + IMU only (no second camera), so the stereo mode that the authors tune and test is not available to us.

**Decision: exclude Kimera-VIO, because mono+IMU is only an optional, unmaintained path whose open issues report fatal errors and poor accuracy even on EuRoC, it is not tested on Ubuntu 22.04, and we have no stereo pair to run the mode it is built for (revisit only as `mono_inertial` on EuRoC if every other method is finished and time remains).**
